DEARLY INVITED — UPLOAD-READY WEBSITE
=====================================

1) WHEN YOU BUY YOUR DOMAIN
   Open  assets/protect.js  and edit the line at the very top:
       var DI_DOMAIN="YOUR-DOMAIN.com";
   e.g. var DI_DOMAIN="dearlyinvited.com";      (no https://, no www — www is covered automatically)
   After that, the site only works on your domain; anywhere else shows "unlicensed copy".
   While it still says YOUR-DOMAIN.com, the site works on any host (only copies opened from a computer are blocked).

2) UPLOAD
   Upload EVERYTHING in this folder (keep the folders exactly as they are) to the root of your hosting,
   so index.html is at  https://your-domain/index.html
   Works on any static host: Netlify, Vercel, GitHub Pages, Cloudflare Pages, Hostinger, cPanel...

3) NOTE
   You can't preview this copy by double-clicking files on your computer — that is the protection working.
   To preview or edit, use the other package (Dearly-Invited-Website.zip, readable code).
   Delete this text file before uploading if you like.
